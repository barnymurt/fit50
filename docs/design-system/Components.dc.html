03 · Marquee.tsx

Marquee

Eight repeated spans, doubled, translated -50% on a linear loop. Lilita One at clamp(5rem, 13vw, 12rem), 48px right padding per item, separator ✦. Sits absolutely in the top 128–208px of a section at z-0, pointer-events off, aria-hidden. Speed is a duration in seconds: 200 for Rules and Workouts, 220 for Calculator, 240 for Tracker.

arrow-right — the only one shipping

11 · Usage

Do / don't

Do

  • Use one primary button per section, and make its label a verb.
  • Pass tone="dark" on ink and teal grounds rather than overriding colors.
  • Replace a submitted form with its confirmation line.
  • Keep habit illustrations at 48px or larger.
  • Give every toggle an aria-pressed and a spoken label.

Don't

  • Override Button padding with !important utilities — add a size prop instead.
  • Mix pill and square buttons in the same panel.
  • Use the SVG habit icons; they're the stale set.
  • Introduce a skeleton loader — the site loads a line of text.
  • Hardcode #FEFEFE / #2A2A2A as the route files do.
