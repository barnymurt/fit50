01 · Composition

The section formula

Every section below the hero is built the same way. Change the ground color and the marquee words; keep everything else.

1 · Marquee band

Absolute, top 0, height 128px (208px at md), z-0, pointer-events none, aria-hidden. The section pads its top to 160px / 224px to clear it.

2 · Statement line

A 7- or 8-column Fraunces paragraph at 30px / 48px, ground text at 85–95%. Two clauses, one em dash or comma. Never a heading tag — the real h2 is screen-reader-only.

3 · Content grid

64–80px below the statement. Cards at 24px gaps, or a bordered list at 1px dividers.

4 · Closing CTA

Centred, 64–80px above the section's bottom padding: an h2-sized Fraunces line, then one primary button. Every section funnels to the tracker.

Cube rules

  • 1px gaps over an ink background make the rules — no borders on the tiles.
  • Untouched: white, ink text, hovering to paper. Done: coral fill, paper text, 300ms.
  • Illustration scales 105% on hover over 300ms.
  • All nine done adds a 4px coral/35 outer ring and the header flips to "Cube solved for today".
  • Past days aren't editable in the cube — the 50-day grid is a read-only history.

Streak logic

  • 7 or more habits in a day extends the streak.
  • 5 or 6 is a hold: neither extend nor reset.
  • Under 5 resets, and banks the run as "best".
  • The numeral is cream on teal — the only place cream carries type.

06 · Responsive · extends the code

On a phone

Everything collapses to one column at md (768px); the tracker splits at lg (1024px). Type scales itself through clamp, so nothing needs a mobile override.

Set by the code

  • Gutters 24px → 40px at md.
  • Panel padding 24px → 40px at md.
  • Marquee band 128px → 208px at md.
  • Cube tile padding 12px → 20px at md.
  • Nav links hide below md.

Open on mobile

  • Nav links vanish below md with nothing replacing them — no drawer, no menu button. The Start button and wordmark are the only navigation on a phone.
  • The 50-day grid keeps ten columns, putting each cell near 28px. Tolerable as a read-only display, but the day numerals fall to the edge of legibility.
  • Cube tiles stay square in three columns, so each is roughly 100px wide — above the 44px minimum, but the caption wraps to three lines.

Rules for new mobile work

  • 44px minimum for anything tappable.
  • Full-width square buttons in panels; keep pills for single marketing CTAs.
  • Stack input-and-button pairs vertically with a 12px gap — the codebase already does this with flex-col sm:flex-row.
  • Never shrink a caption below 12px; drop the label instead.

07 · Voice & usage

How it talks

Short imperatives, second person, no hedging. Periods where you'd expect exclamation marks. Section headlines are two clauses split by a full stop or a dash: "Check the box. Build the streak."

Do

  • Open every section with a marquee, close it with one CTA.
  • Keep the real h2 screen-reader-only when the visible headline is a paragraph.
  • Signal state with fill color, not icons or badges.
  • Let one number dominate: the streak, the day, the count.
  • Write labels as commands — "Next day", "Show Rule", "Start tracking".

Don't

  • Run two marquees in one section, or one on the hero.
  • Add a second CTA next to the closing button.
  • Explain the mechanic twice — the caption above the count already does it.
  • Use exclamation marks outside the FAQ statement line.
  • Congratulate at length; "✓ Done. Well executed." is the ceiling.
