Wrap constrained to align with the rest of the site

The sub-page .wrap was 1240px (matching the original HTMLs) but the rest of the FIT50 site uses max-w-5xl (1024px) for its main content. The sub-pages were visually wider than every other section on the site, breaking the column.

Update in src/styles/on-the-house.css:

  .wrap { max-width: 1024px; margin: 0 auto; padding: 0 24px; }
  @media (min-width: 768px) { .wrap { padding: 0 40px; } }

Now the lavender field, the tile grid, the region blurb, the modal etc all sit in the same column as the homepage content. The 1024px max is wide enough to keep the 4-column tile grid feeling roomy, but narrow enough that the design has the same silhouette as the rest of the site (max-w-5xl mx-auto used everywhere in the homepage and account sections).

Visual details preserved: the Fraunces italic 'em' on the hero h1, the coral-vibrant eyebrow, the pill buttons, the 64px italic Fraunces coral tile numbers, the soft paper cards with the hover lift and coral border. The lavender (#E4DEF3) field, the paper (#FBF7EE) tiles, and the ink-deep (#1A1730) type all unchanged. Just the .wrap width was the mismatch.
