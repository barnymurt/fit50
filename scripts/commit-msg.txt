The default .btn had color: inherit (which would be dark text on a dark background if the theme's text colour was already dark). Fixed:

  - The default .btn picks up color: var(--ink-deep) (the dark text) so standalone <a class="btn"> uses the dark text by default.

The button styling now reads correctly across all three themes (lavender / coral / cream) and the 'text appears the same as the button' issue is gone.
