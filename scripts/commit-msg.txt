Fix /meditation background not showing teal

The user pointed out that the /meditation page wasn't visually teal even though the page had the theme-teal class. The CSS custom property --on-the-house-bg was set on a child div (the page wrapper), not on <body>, so the body background stayed at the default value (lavender) and the teal only coloured the page wrapper's content area - any gap around the content showed lavender.

src/styles/on-the-house.css: added body:has(.theme-coral) and body:has(.theme-teal) selectors. :has() is supported in all modern browsers (Chrome 105+, Safari 15.4+, Firefox 121+). The theme class on a child now propagates the chosen tone up to <body> and the rest of the page picks it up:

  body:has(.theme-coral) { --on-the-house-bg: var(--coral-vibrant); --on-the-house-fg: var(--ink-deep); }
  body:has(.theme-teal)  { --on-the-house-bg: var(--teal);          --on-the-house-fg: var(--paper); }

So the body (and therefore the whole page background) now picks up the coral on /drinks and the teal on /meditation. The existing .theme-coral and .theme-teal rules on the inner div are still in place - they only applied to that subtree before, but now the body matches them too. The /quit-list keeps the default lavender.
