Three sub-pages, three different section tones from the design system

The user asked for:
1. The drinks filter bar to use the same background as its page background (was lavender, now matches whatever tone the page picks).
2. The three sub-pages to each have a different design-system background.
3. The drinks page to be the most colourful using the design system's orange tone.

src/styles/on-the-house.css: introduced a single CSS custom property --on-the-house-bg that drives the page background, the marquee strip, and the sticky filter bar (so the filter bar always matches the page). Three theme classes swap that variable:

  default              = var(--lavender)   - quit list (peaceful, unchanged)
  .theme-coral = var(--coral-vibrant)   - drinks (the brand orange, the most vibrant)
  .theme-cozy  = var(--cream)          - meditation (warm, relaxed, the design system's cosy tone)

Each theme also overrides all the text/icon/button colours that need flipping for contrast against the saturated background. The page background, marquee, and filter bar now swap together via the CSS variable, so the filter bar automatically matches the page (per the user's previous request). The hero, type, and chips all keep their design language - only the background and contrast colours shift.

src/app/account/drinks/page.tsx + src/app/account/meditation/page.tsx: the JSX root is now <div className="theme-coral"> for drinks and <div className="theme-cozy"> for meditation. The wrap div closure on each page is fixed so the JSX is balanced.

Visual result on the three pages:
  - Quit list: lavender (unchanged). Tile cards stay paper. Modal stays paper. Calm.
  - Drinks: coral-vibrant. Tile cards sit at 0.92 alpha on coral so they read as bright but legible. Tiles have a black border and chip text inverted to ink. Eyebrow and small text inverted to ink. The brand's signature orange. The "drinkiest" of the three.
  - Meditation: cream (warm, soft, relaxed). Same alpha-tile trick. Tiles are almost-white on the warm field. The most relaxed of the three.
